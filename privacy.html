Privacy Policy

Last updated: September 23, 2026

1. Overview

HSE-Rclone is a personal integration used by its owner to transfer files with Google Drive. It is not a public file-sharing service.

2. Google Drive Data

The application uses the Google Drive API with the drive.file scope. It accesses and manages files created or opened through the application, solely to perform file operations requested by the account owner.

3. Data Storage

Files uploaded through the application are stored in the owner's Google Drive account. OAuth credentials are stored locally in rclone configuration files on the owner's authorized computers and computing accounts. These credentials are not stored on this website.

4. Data Sharing

The application does not sell user data or share it with advertisers. File transfers are performed directly between the authorized computing environment and Google Drive.

5. Data Retention and Control

The account owner controls the transferred files and can delete them from Google Drive. Access can be revoked through Google Account security settings.
